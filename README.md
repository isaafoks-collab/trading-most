# Мост: агент «Слон-Трейдинг» работает без мастера

- `status.md` — живой отчёт агента. Перезаписывается на каждом значимом шаге. Читается мастером и его помощником (Алисой в чате Яндекса) по прямой ссылке raw-файла
- `serdce.txt` — пульс. Агент касается файла на каждом шаге; страж по времени изменения видит, жив ли агент
- `ochered-komand.txt` — команды от мастера. Пишет только страж, забирает агент
- `strazh-log.txt` — журнал стража: перезапуски, команды, ошибки
- `resheniya.md` — журнал решений (Директива: значимое решение — запись в тот же день)
- Все .ps1 моста — UTF-8 с BOM. После каждой правки стража проверяй кодировку (PowerShell 5.1 читает файл без BOM как ANSI и ломается на кириллице)

Команды от мастера создаются как GitHub Issue с меткой `komanda` в репозитории isaafoks-collab/trading-most. Заголовок issue — это сама команда одной строкой. Страж закрывает issue и кладёт команду в очередь. Ответ агента появится в `status.md` в разделе ОБСУДИТЬ С ЧЕЛОВЕКОМ или СДЕЛАНО.

Жёсткие стопы торгового агента — в AGENTS.md: реальные сделки автономно запрещены всегда, по умолчанию paper trading.
